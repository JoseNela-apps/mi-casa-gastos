# Mi Casa · Gastos — V2 Pro

## Incluye
- Dashboard responsive tipo app.
- 6 personas editables.
- Gastos editables/eliminables.
- División igual o por montos exactos.
- Adjuntar imágenes y PDF.
- Vista previa de comprobantes.
- Saldar pagos.
- Cierre mensual e historial.
- Reporte mensual preparado para guardar como PDF.
- Imágenes de comprobantes incluidas como anexos del reporte.
- PWA instalable y offline.

## GitHub Pages
1. Sube todos los archivos de este ZIP a la raíz del repositorio.
2. GitHub → Settings → Pages.
3. Deploy from a branch → main → /root → Save.

## iPhone
Safari → Compartir → Añadir a pantalla de inicio.

## Importante
Esta primera V2 guarda datos y archivos localmente en cada dispositivo. La siguiente etapa es Firebase/Supabase para login, sincronización familiar y almacenamiento cloud.
